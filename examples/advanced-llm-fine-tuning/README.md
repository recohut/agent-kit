## Run a notebook

In Colab, choose **Runtime → Change runtime type → T4 GPU**, then **Runtime → Run all**. Each notebook lists its pinned software, data and input requirements.

For Lesson 15, keep the verified Lesson 08 run materials together and set `LAB08_HANDOFF_DIR` to that directory before running. The capstone checks the two notebook digests, training feature digest and adapter digest before scoring. The optional `LAB15_STANDALONE_REFIT=1` run records a separate refit.
