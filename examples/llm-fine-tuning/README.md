## Run a notebook

1. Open it in Colab with the badge.
2. Choose **Runtime → Change runtime type → T4 GPU**, then **Runtime → Run all**.
3. No API keys are needed. Public datasets are downloaded from a pinned commit; everything else is created in the
   notebook.

The notebooks pin `transformers 4.51.3`, `peft 0.15.2` and, where they are used, `bitsandbytes 0.50.2` (4-bit models) and `trl 0.19.1` (training), so the code matches the lessons.
